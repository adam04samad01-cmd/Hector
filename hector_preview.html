Hector 1.5 Preview

Admin folder and document upload features are now in the Streamlit app.

Important

This static preview page cannot upload files or save folder changes to your laptop. Browsers block normal HTML files from writing to private folders.

To use Hector 1.5, run the Streamlit app locally. That gives Hector a Python backend that can safely save uploads into the project documents folder and update CSV files.

How To Open Hector 1.5

Open PowerShell in the project folder and run:

streamlit run app.py

The app includes Admin / Manage Folders, folder creation, folder deletion, document uploads, metadata entry, and Open Document links.
